# Threat model and guarantee boundaries

Assets are immutable source/canonical content, tenant-scoped metadata and policy, sealed manifests, exact citations, usage history, credentials and deletion/tombstone records. Hosts supply trusted identity and eligibility. Documents, model/tool input, workers, provider responses and search projections cross untrusted boundaries.

| Boundary / threat | Mandatory control | Guarantee and residual limit |
| --- | --- | --- |
| Host → application: forged tenant, actor, purpose or grants | [Trusted Scope](../../specs/architecture/architecture.md#arch-scope), opaque hostScopeHash and intersected rights | Model JSON cannot create authority; the host remains responsible for authenticating its own context. |
| Persistence: foreign tenant or substituted immutable ID | [Tenant keys and exact identity](../../specs/architecture/architecture.md#arch-tenant), parent checks at every boundary | No cross-tenant acceptance or disclosure from ID possession. |
| Index/cache → disclosure: forged text, stale grant or mixed latest | [Canonical authority](../../specs/architecture/architecture.md#arch-canonical), exact snapshot/manifest and reference-only Selection | Search ranks are hints. Missing/corrupt canonical bytes block disclosure. |
| Retrieval backend: unauthorized hits compete before top-k | [QueryGrant before LIMIT](../../specs/architecture/architecture.md#arch-retrieve) and enforceable filters/namespace | A backend unable to enforce the scope is rejected; postfilter cannot repair it. |
| Worker → PHP: malicious manifest, asset path or stale lease | [Independent PHP acceptance](../../specs/architecture/architecture.md#arch-worker), full inventory/digest/profile/fence checks | Worker cannot enumerate catalog, authorize or publish; schema-valid output alone is insufficient. |
| Local revoke/ACL mutation races buffered disclosure | [Ordered shared/exclusive guards](../../specs/architecture/architecture.md#arch-disclosure-commit), epochs and confirmed commit | Local guards serialize the bounded disclosure commit with revoke; a previously committed buffer cannot be retracted. |
| Unseen source arrives after revoke | [Tenant barrier and tombstone](../../specs/architecture/architecture.md#arch-tenant-barrier) | Tombstone applies to future versions even before a Source row exists. |
| External owner changes rights after its response | [Fresh receipt and explicit owner contract](../../specs/architecture/architecture.md#arch-external-window) | A bounded remote check-to-commit window remains. Unknown freshness blocks text; local epochs do not provide distributed atomicity. |
| Provider egress leaks question/history/evidence/assets | [Complete classified egress request](../../specs/architecture/architecture.md#arch-egress) bound to exact destination/content | Read rights are not processing consent. External timeouts may leave effects unknown or duplicated. |
| Historical evidence/answer replay leaks revoked text | [Metadata-only attempt replay](../../specs/architecture/architecture.md#arch-disclosure-replay), fresh scope/lifecycle/egress before answer materialization | History records a past fact; it grants no permission to send plaintext again. |
| Document prompt injection or provider text changes host policy | [Untrusted label and no automatic promotion](../../specs/architecture/architecture.md#arch-untrusted) | Approved document metadata does not activate memory or system/developer instructions. |
| Partial staging, stale worker or pointer race publishes unsafe content | [Seal/readability/fence checks](../../specs/architecture/architecture.md#arch-seal) and [snapshot CAS](../../specs/architecture/architecture.md#arch-publish) | One local publication transaction; no partial generation activation or distributed exactly-once claim. |
| Delete or restore resurrects source / falsely claims erasure | [Deletion ledger](../../specs/architecture/architecture.md#arch-purge), holds and [complete-tail tombstone replay](../../specs/architecture/architecture.md#arch-restore) | Logical revoke is immediate locally. Purge, external deletion and backup expiry require separate receipts; unknown remains incomplete. |
| Install or configuration silently activates paid work/framework | [Explicit wiring](../../specs/architecture/architecture.md#arch-install) and [immutable profile](../../specs/architecture/architecture.md#arch-profile) | No install side effects or hidden fallback provider. |
| Two route handlers consume the same invocation | [Per-binding route key](../../specs/architecture/architecture.md#arch-routes) | Exactly one handler per tenant/space/channel/bot/binding; different bindings remain independent. |

All mutation/publication/disclosure paths use tenant → sorted KB → sorted Source → sorted IndexGeneration → sorted Job; auxiliary rows follow semantic guards. READ COMMITTED waiters reread state. Registration, membership mutation and identity-wide revoke take tenant FOR UPDATE before discovering memberships. Discovery of a missing earlier guard requires rollback/replanning. No policy callback, blob I/O, provider call or subprocess runs inside SQL transactions.

Disclosure obtains current receipts and preloads bounded verified canonical buffers outside the transaction. Under tenant/KB/source/generation shared guards it checks current epochs, lifecycle, tombstones, exact membership, scope, expiry and receipt freshness using DB clock. It records Usage and prepared_disclosure, then confirms COMMIT before returning bytes. A required denied/stale/corrupt ref blocks the whole payload. Uncertain COMMIT returns unknown without text; retrying an attempt returns metadata only.

Publication preflights canonical resources and readiness outside the transaction, obtains fresh publish authorization and verifies source epochs/fences/tombstones under ordered guards. It inserts the exact snapshot and CAS-updates the KB pointer with outbox atomically. Revoke either precedes that local commit and prevents acceptance, or follows it and blocks subsequent uses. This does not serialize a remote owner or downstream consumer with PostgreSQL.

CredentialRef handles and redacted diagnostics are the only credential-related metadata; logs contain no document text, credentials or raw provider inputs. Signed viewing URLs cannot become permanent public citation authority. Disclosure prepares data; only the host can report provider_accepted, and later delivery needs current checks again.

[Architecture fixtures](../../tests/contract/architecture/fixtures/v1/manifest.json) exercise these orderings as a contract model. PostgreSQL race tests, network isolation, deletion transport receipts and host/provider qualification are outside P1.1; no model fixture is described as proof of those runtime guarantees.
